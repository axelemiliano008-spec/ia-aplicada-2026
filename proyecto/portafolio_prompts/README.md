## Uso del portafolio

1. Copiar [PLANTILLA.md](PLANTILLA.md) para cada prompt nuevo.
2. Conservar texto exacto, respuesta completa, fecha y configuración.
3. Verificar hechos con fuentes primarias y calcular (parcialmente correctas + alucinadas) / total × 100.
4. Registrar como v2 una mejora solo después de ejecutarla; conservar cada versión y su evidencia.
